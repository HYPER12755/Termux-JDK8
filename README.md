# steps to install
1.git clone
```
git clone https://github.com/HYPER12755/Termux-JDK8.git
```
2.
```
cd Termux-JDK8
```
4.
```
chmod +x INSTALL-JDK8
```
5.
```
./INSTALL-JDK8
```
6. one liner setup
```
git clone https://github.com/HYPER12755/Termux-JDK8.git && cd Termux-JDK8 && chmod +x INSTALL-JDK8 &&  ./INSTALL-JDK8 && cd ~ && rmf Termux-JDK8
```
